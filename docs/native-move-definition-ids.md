# Native move-definition ID reads

The native battle resolver accepts a catalog ID as well as its existing move
instance input. This lets presentation readers obtain the actual move name,
type and base PP using the same catalog authority as native turn resolution.
There is no copied definition cache or second move registry. Existing
instance-specific Struggle handling remains unchanged.

ROM-free coverage uses actual native battles across ten editions, live catalog
replacement, missing IDs, PP preservation and real native damage execution.
It does not establish complete client/model-view, GPU or release compatibility.
