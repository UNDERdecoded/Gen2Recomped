# Native GSC progression and learning: upstream offer

This offer builds on #403 and its stated dependencies. The independently
qualified older-host implementation is 7f288aa5ff5bd8dd847ba4914024044453767867.
Original upstream main was 8d5b4387420cc1fdcadf58ad4ca78a7d8596e41d when the
combined source was prepared. No source options-record constructor is added
or claimed by this payload.

Eleven source Mon methods share real native growth, five-word stat experience,
progression/stat replacement and move-learning owners. Source experience is a
live alias to native exp. The existing source movesAtLevel spelling returns
slot records, including without move definitions. Native/source arrival uses
the rolling four-slot window, allowing a forgotten move to be relearned.

GSC rounding evaluates the level portion before participant division;
EXP.SHARE halves the base pool first. Real callbacks receive actual recipient
counts and half/egg flags. Stat effort uses Special Attack, half/divide before
Pokerus doubling, with a single native byte reader. Hooks precede effort;
final level/stats/HP precede crossed-level events. Ordinary native wrappers
follow replaced stats, while independent Transform views retain ownership.
Growth overrides and ROM coefficient rows use one evaluator.

The older native Experience.apply kept its award and progression in one
function. Its existing progression tail is now the actual shared add owner;
non-GSC behavior is retained. Only the real MON_PKRS byte reader is a new
needed dependency, not unrelated infection/clock lifecycle implementations.
The preserved older RNG constructor is not replaced by an unqualified newer
options adapter. Native/source learning uses the same actual slot/event
owner. No fixtures assert a simulated service or change expected outcomes.

Eight independently run selected groups passed:

- source/pure progression: 2,519,385 checks;
- actual SDK/native progression: 595;
- existing native APIs/rounding across generations: 5,295;
- source/native learning and rolling arrivals: 188;
- native source stat refresh: 238;
- native source fields: 170;
- native PP: 6,642;
- native caught-data arrivals/consumers: 133.

These are selected ROM-free semantics on the real older composed host, not
full official suites, GPU/window/Windows/macOS packages, full Mon/Battle API
or complete VASC acceptance. Supplied mods, ROMs, Gen1 and player profiles
were not edited. The fork integration has separate exact-tree/CI gates.
