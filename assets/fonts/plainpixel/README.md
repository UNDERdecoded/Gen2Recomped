# Plain Pixel font

"Plain Pixel Font" by Douglas Vautour (Burpy Fresh), licensed under
[Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).
Source: [the author's Plain Pixel page](https://burpyfresh.itch.io/plain-pixel).

This is the unmodified version 0.009 bundled by Gen1Recomp at commit
`535a5ec088c1ae1bf4d91dd3e35a56f64cf46d91`, retained here for matching
font metrics and glyphs. The font is third-party material and is not covered
by this fork's contribution licence.

It is used only when a mod opts in with `mod.content.font:register("ttf", {})`.
The ROM font remains the default. The default size is 15, with monochrome
rasterization at DPI 1 and nearest filtering. A mod can supply its own font
using the `file` field instead.
